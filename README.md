# ไร่สุขอนันต์ POS — Demo

ตัวอย่างระบบขายหน้าร้านแบบ Static Web App สำหรับทดลองใช้งาน

**ทดลองใช้งาน:** https://tyne-tn.github.io/rai-suk-anan-pos-demo/

## ฟังก์ชันตัวอย่าง

- หน้าขายและตะกร้าสินค้า
- รับชำระด้วยเงินสดหรือ QR และคำนวณเงินทอน
- รายการขายและการยกเลิกบิล
- รายงานยอดขาย
- จัดการรายการสินค้า
- ส่งออกข้อมูลสำรอง JSON

> ข้อมูลถูกบันทึกใน `localStorage` ของเบราว์เซอร์เครื่องที่ใช้งานเท่านั้น ตัวอย่างนี้ยังไม่มีฐานข้อมูลกลาง ระบบเข้าสู่ระบบ หรือการซิงก์หลายเครื่อง
